01消化系統總覽（3D）

消化 = 大分子水解成單體（在消化道管腔，由專一酵素催化），再經黏膜吸收進入血液或淋巴。看食團（黃球）從口一路到直腸。

運動 Motility

攝食、咀嚼、吞嚥、蠕動、分節

分泌 Secretion

外分泌（酵素、HCl、黏液、膽汁）與內分泌（胃泌素、胰泌素、CCK…）

消化 Digestion

水解：澱粉 → 單醣、蛋白 → 胺基酸、脂肪 → 脂肪酸 + 單酸甘油酯

吸收 Absorption

主要在小腸；單醣、胺基酸入肝門靜脈；脂質入乳糜管

02消化道管壁的四層（3D）

由內而外：黏膜（上皮、固有層、黏膜肌層）→ 黏膜下層（黏膜下神經叢）→ 肌層（內環、外縱；之間為肌間神經叢）→ 漿膜（臟層腹膜）。切換看蠕動與分節運動。

03胃：胃酸與胃蛋白酶

壁細胞：上＝胃腔，下＝血液
  • 胃分為賁門、胃底、胃體、幽門（竇）；內壁有皺襞，胃小凹通往胃腺
  • 胃腺細胞：黏液頸細胞、壁細胞（HCl + 內在因子）、主細胞（胃蛋白酶原）、ECL 細胞（組織胺）、G 細胞（胃泌素）、P/D1 細胞（飢餓素 ghrelin）
  • 壁細胞以 H⁺/K⁺ ATPase（質子幫浦）主動分泌 H⁺（pH 可低至 0.8）；基底側以 HCO₃⁻ 交換 Cl⁻（餐後「鹼潮」）
  • 刺激：胃泌素（主要間接經 ECL 的組織胺）、組織胺（H₂ 受體）、ACh（迷走）
  • 酸性下胃蛋白酶原 → 胃蛋白酶（自我催化）；胃唯一攸關生命的功能是分泌內在因子（B₁₂ 吸收）

消化性潰瘍

胃或十二指腸黏膜被 HCl 侵蝕；多數患者感染幽門螺旋桿菌（或使用 NSAIDs）。治療：PPI + 抗生素；根除 H. pylori 可治癒 80% 以上十二指腸潰瘍。

胃食道逆流 GERD

酸性食糜逆流 → 胸口灼熱；長期可變成巴瑞特食道。下食道括約肌控制；PPI（omeprazole）抑制質子幫浦。

胃的保護

黏液 + HCO₃⁻ 屏障、上皮緊密接合、細胞快速更新；酒精與 NSAIDs 會破壞屏障。

04小腸：絨毛、微絨毛與吸收（3D）

小腸 = 十二指腸 → 空腸 → 迴腸。環狀皺褶、絨毛、微絨毛（刷狀緣）大幅增加表面積；刷狀緣上有刷狀緣酵素完成消化。中間那根絨毛剖開看內部。

白＝單醣　綠＝胺基酸　黃＝乳糜微粒
點選構造

刷狀緣酵素

  • 雙醣酶：蔗糖酶、麥芽糖酶、乳糖酶（缺乏 → 乳糖不耐）
  • 胺肽酶等：完成蛋白質消化
  • 腸激酶（腸肽酶）：活化胰蛋白酶原

腸腺（Lieberkühn 隱窩）

隱窩底部的幹細胞產生新上皮細胞，往絨毛頂端推移並脫落（約數天更新一次）；Paneth 細胞分泌抗菌物質。

小腸運動

蠕動推進；分節混合食糜。節律由 Cajal 間質細胞（電節律起搏）產生的慢波決定；兩餐之間有遷移運動複合波清空小腸。

05肝臟：肝小葉（3D）

血液從小葉周邊的門脈三合體（肝動脈 + 肝門靜脈分支）經竇狀隙流向中央靜脈；膽汁在肝細胞板之間的膽小管中反向流向周邊的膽小管。

紅/紫＝血流向中心　綠＝膽汁向外

肝臟的功能

  • 解毒：排入膽汁、Kupffer 細胞吞噬、化學轉化（使藥物更水溶以利腎排除）
  • 醣類：肝醣生成/分解、糖質新生
  • 脂質：脂蛋白、膽固醇、酮體
  • 製造血漿蛋白：白蛋白、凝血因子、血管張力素原
  • 分泌膽汁：膽鹽、膽紅素、膽固醇、磷脂
  • 儲存：肝醣、鐵、維生素

膽汁與膽囊

07消化的調控

① 頭期

看、聞、想到食物 → 高等腦區 → 迷走神經 → 胃液分泌（約佔 30%）。

② 胃期

食物（胜肽、胺基酸）與胃擴張 → G 細胞分泌胃泌素 → HCl、胃蛋白酶原；pH < 2.5 時負回饋抑制胃泌素。

③ 腸期

食糜進入十二指腸 → 神經反射與激素（腸抑胃素：胰泌素、CCK、GIP 等）抑制胃排空與分泌，保護小腸。

胰泌素與 CCK

腸神經系統與短反射

  • 「腸腦」：感覺神經元、中間神經元、自主運動神經元（黏膜下與肌間神經叢）
  • 蠕動：食團上方收縮、下方放鬆
  • 胃迴腸反射（胃活動增加迴腸運動）、迴胃反射（迴腸擴張抑制胃）、腸–腸反射

09大腸

構造

盲腸（附闌尾）→ 升結腸 → 橫結腸 → 降結腸 → 乙狀結腸 → 直腸 → 肛管；壁上的膨出稱結腸袋。

腸道菌叢

共生細菌在大腸最多：製造部分 B 群維生素與維生素 K、短鏈脂肪酸；保護腸道免於病原菌引起的發炎反應。

水與電解質、排便

每天 1.5–2.0 L 進入大腸，吸收約 90%（Na⁺ 主動吸收、水跟隨）。排便：肛門括約肌放鬆 + 其他肌肉收縮提高直腸壓。
