酵素與能量

3D 酵素與受質（鎖與鑰匙、誘導契合、異位抑制）、活化能與分子能量分布、溫度／pH／受質濃度試算、可逆反應的 3D 天平、代謝途徑與先天代謝缺陷模擬、3D ATP 分子水解與合成、氧化還原。

酵素催化活化能命名與同功酶影響因素可逆反應代謝途徑ATP氧化還原快閃卡測驗

01酵素是生物催化劑

受質嵌入酵素的活性部位形成酵素–受質複合體：受質被擺成正確方向、原有的鍵被削弱，新鍵更容易形成。反應後酵素本身不變，可重複使用。

青色＝酵素　黃＝活性部位　紅＝異位部位

催化劑的特性

  • 加快反應速率
  • 反應後本身不被改變
  • 不改變反應的最終結果（平衡）
  • 方法：降低活化能

酵素多為蛋白質

  • 特定的三維形狀由胺基酸序列（基因）決定
  • 專一性：只有形狀相符的受質能進入活性部位
  • 少數 RNA 也有催化能力（核酶）

酵素的活化

  • 有些酵素先以非活性形式產生
  • 磷酸化（由蛋白激酶催化）可活化或抑制；去磷酸化則相反
  • 蛋白激酶本身可能需要第二傳訊者 cAMP 才活化（第 11 章）

02活化能與溫度

活化能＝反應物分子要參與反應所需的能量。沒有催化劑時只有少數分子具備足夠能量；酵素降低門檻 → 更多分子能反應 → 速率上升。

03酵素的命名、同功酶與臨床診斷

命名

  • 字尾多為 -ase，並指出受質與工作類型：乳酸脫氫酶從乳酸移除氫
  • 例：catalase（2H₂O₂ → 2H₂O + O₂）、碳酸酐酶（H₂CO₃ → H₂O + CO₂）、澱粉酶（澱粉 + H₂O → 麥芽糖）
  • 同功酶 isoenzymes：催化相同反應、但結構不同的酵素（由不同基因編碼）

輔因子與輔酶

  • 輔因子 cofactor：金屬離子（Ca²⁺、Mg²⁺、Mn²⁺、Cu²⁺、Zn²⁺ 等），改變活性部位形狀或參與結合
  • 輔酶 coenzyme：小型有機分子，衍生自水溶性維生素（菸鹼酸 → NAD、核黃素 → FAD）
  • 輔酶在酵素之間運送氫原子與小分子受質
  • 酵素也會被分解與再合成（turnover）調節數量

05可逆反應與質量作用定律

同一個酵素可催化正反兩個方向。反應方向取決於兩側濃度：質量作用定律。例：碳酸酐酶 CO₂ + H₂O ⇄ H₂CO₃。

07生物能量學與 ATP

熱力學第一定律：能量不生不滅，只轉換形式；第二定律：每次轉換都使熵（亂度）增加、可用的自由能減少。細胞把放能反應與吸能反應偶聯：分解食物 → 合成 ATP；分解 ATP → 驅動耗能工作。

    08氧化還原反應與 NAD、FAD

    定義

    • 氧化：失去電子（常以失去氫原子的形式）；還原：得到電子
    • 還原劑 = 電子提供者；氧化劑 = 電子接受者
    • 兩者必定偶聯：一方被氧化，另一方就被還原
    • 「氧化」不一定有氧參與；但氧是細胞內最終的電子接受者
    分子 X–H₂被氧化
    →
    NAD⁺ → NADH + H⁺NAD 被還原（作氧化劑）
    →
    NADH → NAD⁺NADH 被氧化（作還原劑）
    →
    分子 Y → Y–H₂被還原

    NAD 與 FAD

    • NAD（菸鹼醯胺腺嘌呤二核苷酸）← 菸鹼酸（維生素 B₃）；接受 2 個電子 + 1 個質子：NAD⁺ + 2H → NADH + H⁺
    • FAD（黃素腺嘌呤二核苷酸）← 核黃素（維生素 B₂）；接受 2 電子 + 2 質子：FAD + 2H → FADH₂
    • 還原態的 NADH、FADH₂ 把電子帶到電子傳遞鏈，最後交給 O₂ → 產生 ATP（第 5 章）
    • 菸鹼酸缺乏 → 糙皮病 pellagra
