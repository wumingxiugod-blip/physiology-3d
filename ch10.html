01感覺受器的特性

依刺激能量分類

  • 化學受器：味、嗅、血液 pH 等
  • 光受器：視桿、視錐
  • 溫度受器：冷、熱
  • 機械受器：觸、壓、聽、平衡
  • 痛覺受器：組織傷害
  • 本體感受器：肌肉、肌腱、關節
  • 特殊感覺：視、聽、味、嗅、平衡

特定神經能量定律

  • 每種受器對某一種刺激的閾值最低 → 適當刺激
  • 任何方式刺激該感覺神經，腦都解讀為該適當刺激（例：按壓眼球看到「光」）

發生器電位

感覺神經末梢的分級去極化，大小與刺激強度成正比；達閾值後，強度愈大 → 動作電位頻率愈高。

張力性 vs 相位性受器（適應）

  • 張力性 tonic：刺激持續就一直發放 → 監測刺激的存在與強度（如梅克爾盤）
  • 相位性 phasic：只對刺激改變反應（開始與結束），持續刺激時停止 → 感覺適應（如巴齊尼氏小體、麥斯納小體）
  • 例：穿上衣服後很快就感覺不到衣服

接受域愈小、受器愈密 → 兩點閾愈小、敏銳度愈高（指尖、舌尖）。側抑制抑制周圍較弱刺激的神經元，使感覺更銳利。

轉移痛 Referred pain：內臟受損的痛覺可能被感覺在體表（如心肌缺血 → 左臂痛），因為內臟與體表的感覺神經在脊髓同一節段匯聚。幻肢：截肢者仍感覺失去的肢體。

味覺：五種基本味

味蕾（50–100 個上皮細胞，桶狀）主要位在舌背的乳頭：前方蕈狀、後方輪廓狀、側面葉狀乳頭。

嗅覺

  • 嗅覺受器是雙極神經元，位於嗅上皮；軸突穿過篩板到嗅球
  • 在嗅球的嗅小球與僧帽細胞、簇細胞（次級神經元）突觸 → 嗅徑 → 額葉、內側顳葉（含邊緣系統）
  • 每個嗅覺神經元只表現一種受體蛋白（約 380 種功能性受體；章末摘要寫可達 1,000 種），組合起來可辨識約 10,000 種氣味
  • 氣味分子結合受體 → 大量 G 蛋白次單元解離 → 放大 → 極度敏感

04前庭器官與平衡

三個半規管（彼此近乎垂直）感受角加速度；橢圓囊、球狀囊（耳石器官）感受直線加速度。播放旋轉：開始轉時內淋巴因慣性「落後」→ 頂帽彎曲；等速旋轉時恢復；突然停止時內淋巴繼續流 → 反向彎曲（眼球震顫、眩暈）。

每個毛細胞有 20–50 根靜纖毛與 1 根動纖毛。彎向動纖毛 → 去極化、傳遞物↑、感覺神經放電↑；反方向 → 過極化、放電↓。前庭神經（VIII）→ 小腦與延腦前庭核 → 動眼中樞（眼球運動）。

05耳朵與聽覺

聲波 → 鼓膜 → 聽小骨（錘、砧、鐙）→ 卵圓窗 → 前庭階的外淋巴行進波 → 基底膜振動 → 柯蒂氏器毛細胞的纖毛抵著覆膜彎曲。切換「展開耳蝸」並拉頻率：高頻在基部（近鐙骨）、低頻在頂部（近蝸孔）。

點選構造

人耳可聽 20–20,000 Hz；強度以分貝（dB）表示。

耳蝸的三個腔

  • 前庭階（外淋巴）↔ 卵圓窗
  • 蝸管 / 中階（內淋巴，高 K⁺、+80 mV）
  • 鼓階（外淋巴）↔ 圓窗
  • 前庭膜分隔前庭階與蝸管；基底膜分隔蝸管與鼓階

毛細胞

  • 內毛細胞約 3,500 個（1 排）：真正的感覺細胞 → 螺旋神經節（麩胺酸）
  • 外毛細胞約 11,000 個（3–5 排）：去極化縮短、過極化伸長 → 主動放大基底膜振動
  • 纖毛彎向最高者 → K⁺ 通道開、K⁺ 由內淋巴流入 → 去極化

聽力損失

  • 傳導性：聲波無法傳到內耳（耳垢、中耳炎、耳硬化症）→ 助聽器、手術
  • 感覺神經性：毛細胞或神經受損（噪音、藥物、老化）→ 人工電子耳
  • 聲源定位：兩耳到達的時間差與強度差

老花與散光

老花：年紀增加（多在 45 歲後）水晶體彈性降低，近點變遠 → 老花眼鏡。散光：角膜/水晶體不對稱，各方向屈光不同。

07視網膜、光轉導與色覺

光停止「暗電流」

  • 黑暗：cGMP 使 Na⁺ 通道開 → 暗電流 → 部分去極化 → 持續釋放（抑制性）傳遞物
  • 光：11-cis 視黃醛 → 全反式，視紫質「漂白」→ G 蛋白（轉導蛋白）→ 磷酸二酯酶把 cGMP → GMP → Na⁺ 通道關 → 過極化 → 傳遞物↓ → 雙極細胞解除抑制
  • 一個光子可阻止 > 100 萬個 Na⁺ 進入
  • 全反式 → 11-cis 的再異構化由色素上皮完成（視循環）

08視覺路徑（3D）與病灶
