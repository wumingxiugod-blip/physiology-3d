01神經系統的組成

神經系統分成中樞與周邊兩部分，由兩大類細胞組成。

🧠

CNS vs PNS

  • CNS 中樞＝腦 + 脊髓
  • PNS 周邊＝腦神經 + 脊神經
🔬

兩類細胞

  • 神經元 Neurons：神經系統的功能單位
  • 膠細胞 Glial cells（支持細胞）：維持恆定；數量約為神經元的 5 倍
⚡

神經元的工作

  • 對刺激產生反應
  • 產生並傳送電化學衝動
  • 釋放化學訊息（神經傳遞物）

功能分類 Functional

類型方向/位置
感覺神經元 Sensory / Afferent 傳入把衝動傳入 CNS
運動神經元 Motor / Efferent 輸出把衝動傳出 CNS
聯絡神經元 Association / Interneuron整合神經活動；完全位於 CNS 內

構造分類 Structural

  • Pseudounipolar 假單極：細胞體位在單一突起的側邊
  • Bipolar 雙極：樹突與軸突由細胞體兩端伸出
  • Multipolar 多極：許多樹突＋一條軸突

03支持細胞（膠細胞）與再生

PNS

Schwann cell 許旺細胞

  • 形成 PNS 軸突的髓鞘
  • 每個只包 1 條軸突、約 1 mm，一圈圈纏繞
  • 軸突斷裂後存活並形成再生管
PNS

Satellite cell 衛星細胞

  • PNS 中的另一種膠細胞，包圍神經節內的神經元細胞體
CNS

Oligodendrocyte 寡樹突膠細胞

  • 一個可替多條 CNS 軸突形成髓鞘
  • 產生抑制軸突再生的蛋白，並形成膠質疤痕
CNS

Astrocyte 星形膠質細胞

  • 最多的膠細胞
  • 緩衝細胞外 K⁺
  • 回收神經傳遞物
  • 調節成人神經新生
  • 釋放傳遞物調節神經元活性
  • 誘導形成血腦障壁
CNS

Microglia 微膠細胞

  • 參與神經系統的維護（CNS 的吞噬/免疫防衛）
CNS

Ependymal cell 室管膜細胞

  • 內襯腦室與中央管
  • 似乎是神經幹細胞

🛡️ 血腦障壁 BBB

只讓特定物質（如 O₂、CO₂、glucose）進入腦；由腦微血管特化而成，似乎由 astrocyte 誘導。

  1. 內皮細胞以緊密接合相連，沒有一般組織的縫隙
  2. 內皮外有連續的基底膜
  3. 約 85% 管壁外表被膠細胞終足包圍

🔁 軸突再生

PNS 遠比 CNS 容易。PNS 軸突被切斷時：

  1. 遠端軸突退化
  2. Schwann cells 存活並形成再生管
  3. 再生管釋放化學物質吸引生長中的軸突
  4. 引導軸突長回突觸位置

CNS：寡樹突膠細胞的抑制蛋白＋膠質疤痕阻擋再生。

🌱 神經滋養因子 Neurotrophins

  • 促進胎兒神經生長
  • 許多成人神經元存活所必需
  • 對再生很重要

04膜電位與 Nernst 方程式

膜電位＝膜兩側的電荷差。靜止時細胞內帶負電，離子分布不均。

①

大陰離子被困在細胞內

蛋白質、磷酸根等無法離開，使細胞內偏負，吸引可擴散的陽離子（K⁺）進入。

②

Na⁺/K⁺ ATPase

主動把 Na⁺ 送出；膜對 Na⁺ 通透性低 → Na⁺ 留在胞外。每次 3 Na⁺ 出、2 K⁺ 進，是生電性 electrogenic，約貢獻 −3 mV。

③

K⁺ 高通透、細胞內濃度高

K⁺ 被陰離子吸引進入，又被濃度梯度推出；兩力相等時即 K⁺ 平衡電位 EK ≈ −90 mV。

🧮 Nernst 計算器

Ex = (61 / z) · log10( [X]out / [X]in )

可興奮性 Excitability

可興奮細胞（神經、肌肉）能藉離子通透性的快速改變，迅速「放掉」RMP，用來產生與傳導衝動。

膜電位變化名詞

  • 去極化 Depolarization：MP 變得更正
  • 過極化 Hyperpolarization：比 RMP 更負
  • 再極化 Repolarization：回到 RMP

量法：一電極在細胞內、一電極在細胞外。

講義數值

  • EK = 61/1 · log(5/150) = −90 mV
  • ENa = 61/1 · log(145/12) ≈ +60 mV（精算約 +66）
  • RMP 一般 −65 ~ −85 mV

05動作電位 Action Potential

AP 是沿軸突由細胞體掃向突觸的膜電位波：Na⁺ 內流造成快速去極化，接著 K⁺ 外流造成快速再極化。拖動時間軸或按播放。

靜止

膜電位−70 mV

VG K⁺ 通道關閉
不反應期—

重點

  • 正回饋：達閾值 → VG Na⁺ 開 → Na⁺ 內流 → 更去極化 → 更多通道打開；MP 由 −70 衝到 +30 mV
  • 全有全無：一旦達閾值就不可逆地發放；Na⁺ 通道打開後很快關閉並失活，直到再極化
  • 去/再極化都靠擴散，不需主動運輸；AP 之後由 Na⁺/K⁺ pump 把 Na⁺ 排出、K⁺ 收回
  • 絕對不反應期：Na⁺ 通道失活，無法再產生 AP
  • 相對不反應期：VG K⁺ 通道仍開，較難去極化到閾值（需更強刺激）

📶 刺激強度如何編碼？

刺激越強 → AP 頻率越高；但每個 AP 的大小不變（全有全無）。

電位閘控離子通道模型

  • 通道蛋白具電壓感應器，膜電位改變時構形改變而開/關
  • VG Na⁺：活化閘快開；之後失活閘塞住孔道 → 失活
  • VG K⁺：較慢打開、較慢關閉 → 造成短暫過極化
口訣：Na⁺ 快進快關（失活）、K⁺ 慢開慢關；Na⁺ 造成上升支，K⁺ 造成下降支。

06軸突傳導

纜線性質 Cable properties

  • 軸突本身傳導電流的能力
  • 細胞質電阻高
  • 直徑越大 → 電阻越小
  • 電流會經離子通道洩漏出去

無髓鞘軸突

  • 軸丘達閾值發放 AP → Na⁺ 內流使相鄰區域去極化到閾值 → 再產生新 AP
  • 沿軸突一路重複 → AP 振幅始終相同
  • 傳導慢

有髓鞘軸突：跳躍傳導

  • 髓鞘下離子無法通過 → 不產生 AP、電流不洩漏 → 電流擴散更遠
  • VG Na⁺ 通道只在蘭氏結
  • 一個結的 AP 電流使下一結達閾值 → AP 在結之間「跳」 → saltatory conduction，快

👉 回到 3D 神經元 切換「有髓鞘 / 無髓鞘」可直接比較兩種傳導。

07突觸傳遞 3D

突觸是神經元（突觸前）與另一細胞（突觸後）的功能連接。化學突觸靠神經傳遞物 NT；電突觸在神經系統中較少見。

化學突觸 · 拖曳旋轉 · 點選結構

電突觸 Electrical synapse

  • 去極化經間隙接合 gap junctions 由突觸前直接流到突觸後細胞
  • 由 connexin 蛋白構成
  • 見於平滑肌、心肌、腦與膠細胞

化學突觸 Chemical synapse

  • 突觸裂隙分隔突觸前終扣與突觸後細胞
  • NT 存在突觸小泡中，以胞吐釋放
  • 釋放量取決於 AP 頻率
  • 釋放很快：小泡在 AP 到達前就已停靠在釋放位置（融合複合體）

空間加成 Spatial summation

不同突觸的 EPSP 同時出現在突觸後細胞而加總。纜線性質讓 EPSP 隨時間與距離快速衰退。

時間加成 Temporal summation

同一個突觸前神經元短時間內連續刺激，前一個 EPSP 還沒消退就疊上下一個。

軸丘 Axon hillock

VG 通道多，是 AP 正常的起始處；EPSP 與 IPSP 在此加總達閾值才產生新 AP。

突觸可塑性

  • 重複使用可增加或減少傳遞的容易度＝突觸促進 / 突觸抑壓
  • 高頻刺激常造成興奮性增強＝長期增益 LTP，被認為是學習的基礎

突觸後抑制

  • GABA 與 glycine 產生 IPSP
  • IPSP 抵銷 EPSP → 更難達閾值

突觸前抑制

  • 一個神經元與另一神經元的軸突或終扣形成突觸，抑制其 NT 釋放
