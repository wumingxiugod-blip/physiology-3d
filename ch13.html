紅血球（圓盤）、白血球（白色大顆，可看到細胞核）、血小板（黃色小點）。

① 血漿 Plasma（液體部分）

離心後（補充）：血漿約 55%、白血球血小板層 <1%、紅血球約 45%

  • 血漿蛋白佔血漿 7–9%
  • 白蛋白 Albumin（60–80%）：產生滲透壓，把組織的水拉回微血管 → 維持血量與血壓
  • 球蛋白 Globulins：α、β 球蛋白攜帶脂質；γ 球蛋白＝抗體
  • 纖維蛋白原 Fibrinogen（4%）：轉成不可溶的纖維蛋白 fibrin → 凝血
  • 血清 Serum：血漿去掉凝血蛋白（纖維蛋白原）後的液體

② 紅血球 RBC

  • 攜帶 O₂
  • 無細胞核、無粒線體 → 進行無氧呼吸
  • 壽命 120 天
  • 含血紅素（hemoglobin）與 transferrin

④ 血小板 Platelets

  • 最小的有形成分，無細胞核
  • 壽命很短（5–9 天）
  • 參與凝血，需要纖維蛋白原

③ 白血球 WBC

有細胞核與粒線體。

  • 顆粒型：嗜中性球 neutrophil、嗜酸性球 eosinophil、嗜鹼性球 basophil
  • 非顆粒型：單核球 monocyte、淋巴球 lymphocyte

04紅血球抗原與血型

抗原在細胞表面讓免疫系統辨認「自己」；淋巴球對外來細胞分泌抗體。人會有對抗自己沒有的抗原的抗體。選擇捐血者與受血者看會不會凝集。

輸血反應

輸錯血型時，受血者的抗體與捐血者紅血球結合 → 凝集 agglutination。凝集反應也可用來驗血型。

Rh 因子與懷孕

  • Rh 抗原 = D 抗原（名稱來自 rhesus monkey）；Rh+ 較常見
  • Rh− 母親在分娩時接觸 Rh+ 胎兒血 → 產生抗體
  • 下次懷孕抗體穿過胎盤攻擊胎兒紅血球 → 胎兒紅血球母細胞增多症 / 新生兒溶血症
  • 預防：分娩後給 Rh− 母親 RhoGAM（抗 Rh 抗體），使來自胎兒的 Rh 抗原失去活性

動物：狗的血型

  • 以 DEA（Dog Erythrocyte Antigen）區分：DEA1(−)、1.1、1.2、3、4、5、6、7、8…
  • 最常見且最需注意：DEA1(−)、1.1、1.2
  • 首次輸血通常不排斥；但體內最多只能存在兩種血型 → 再次輸血只能接受自身與第一次的血型
  • 動物血型也可用來鑑別疾病，例如豬的 PSS（Porcine Stress Syndrome）

05止血與凝血 Hemostasis

完整內皮：防止凝血

  • 分泌 前列腺環素 PGI₂ 與 NO → 血管舒張、抑制血小板聚集
  • CD39：把 ADP 分解成 AMP + Pi → 進一步抑制聚集

受損：血小板栓

  1. 膠原暴露，血小板結合膠原
  2. von Willebrand factor 把它們固定住
  3. 血小板釋放反應：分泌 ADP（使血小板變黏）、serotonin（血管收縮）、thromboxane A₂（變黏 + 收縮）→ 招來更多血小板形成栓

止血三步驟

  1. 血管收縮
  2. 形成血小板栓
  3. 形成纖維蛋白網

→ 可在上方「血液 3D」按止血過程觀看。

凝血級聯：點路徑看反應順序，再加入抗凝血劑看哪裡被阻斷

抗凝血劑：

內在路徑 Intrinsic（膠原暴露活化）

膠原暴露→XII → XIIa→XI → XIa→IX → IXa→+ VIIIa、Ca²⁺、磷脂

外在路徑 Extrinsic（較直接）

組織受損→組織因子（III）→VII → VIIa→+ Ca²⁺

共同路徑 Common

X → Xa→+ Va、Ca²⁺、磷脂→凝血酶原（II）→凝血酶 Thrombin→纖維蛋白原 → 纖維蛋白→XIII 交聯 → 血塊

抗凝血劑 Anticoagulants

  • 鈣螯合劑（檸檬酸鈉 sodium citrate、EDTA）：移除 Ca²⁺
  • Heparin：阻斷凝血酶 thrombin
  • Coumarin：抑制維生素 K（兩條路徑都需要；圖中 K 為需維生素 K 合成的因子）

補充：級聯中的因子編號依教科書標準圖；講義重點為 XII（內在起點）、III（外在起點）、Ca²⁺ 與磷脂、凝血酶原 → 凝血酶 → 纖維蛋白原 → 纖維蛋白、維生素 K。

心週期 Cardiac cycle

目前階段—

心音—
  1. 心室開始收縮、壓力上升 → AV 瓣關閉（Lub 隆）
  2. 壓力夠大 → 半月瓣打開，血液射入動脈
  3. 心室壓力下降 → 半月瓣關閉（Dub 咚）
  4. 心室壓力低於心房 → AV 瓣打開，心室充血
  5. 心房收縮，把最後的血送入心室

四個腔室

  • 左心室：把充氧血泵到全身
  • 右心室：把缺氧血泵到肺
  • 左心房：接收來自肺的充氧血
  • 右心房：接收來自全身的缺氧血

體循環與肺循環

  • 體循環：心臟 ↔ 身體組織；經主動脈送出，經上、下腔靜脈回心
  • 肺循環：心臟 ↔ 肺；經肺動脈送到肺，經肺靜脈回心

纖維性骨架 Fibrous skeleton

  • 結締組織，把心房與心室分開（也是電性隔開）→ 心房作為一個單位、心室作為另一單位
  • 形成纖維環 annuli fibrosi，固定心瓣膜

心瓣膜

  • 房室瓣：三尖瓣（右）、二尖瓣（左）
  • 半月瓣：肺動脈瓣（右心室 → 肺動脈幹）、主動脈瓣（左心室 → 主動脈）

心音 Heart sounds

  • 由瓣膜關閉產生
  • Lub 隆＝AV 瓣關閉，發生於心室收縮期；在 QRS 之後
  • Dub 咚＝半月瓣關閉，發生於心室舒張期；講義：在 T 波開始時

心雜音 Heart murmur

  • 異常血流造成的異常心音，多由瓣膜缺損引起
  • 僧帽瓣狹窄：瓣膜鈣化阻礙左心房 → 左心室 → 可能肺高壓
  • 閉鎖不全：關不緊，可能因乳頭狀肌受損
  • 中膈缺損：心房或心室中膈有洞，血液跨到另一側

動物心臟病變（講義圖片重點）

黑色區域：組織病變或壞死

花椰菜狀病變：血栓附著，常在瓣膜上

中膈破洞：連通左右心

Shaggy heart：心包膜感染造成纖維性物質包覆

心臟位於胸腔，呈漏斗狀中空肌肉器官，包在心包膜 pericardium 內。

07心臟的電活動與心電圖

竇房結的節律點電位

SA node 竇房結：節律器

  • 位於右心房
  • 節律點電位：緩慢自發去極化，由 −60 mV 到 −40 mV（HCN 通道：hyperpolarization-activated cyclic nucleotide channels）
  • 到 −40 mV 時 VG Ca²⁺ 通道打開 → 動作電位與收縮
  • VG K⁺ 通道打開、K⁺ 外流 → 再極化
  • NE / E：cAMP↑ → 讓 Na⁺（HCN）通道保持開啟 → 心率加快
  • 副交感 ACh：打開 K⁺ 通道 → 心率變慢

心肌細胞間的連接

  • 以間盤 intercalated discs（間隙接合）相連，刺激由細胞傳到細胞
  • 一次刺激所收縮的區域稱為 myocardium；心房與心室被纖維性骨架電性隔開

心電圖 ECG

  • 記錄心臟電活動造成的體內離子移動
  • P 波：心房去極化
  • QRS 波：心室去極化
  • S-T 段：高原期 plateau
  • T 波：心室再極化

導程 Leads

  • 雙極肢導程：Lead I、II、III（電極在手腕與腿）
  • Lead II：右手–左腳；Lead III：左手–左腳
  • 單極導程：身上電極對機器內的接地：肢導程 aVR、aVL、aVF ＋ 6 個胸導程
講義更正提醒：講義寫 Lead I 為「right arm – right leg」，標準定義是 右手 – 左手（右腳為接地）。考試若依講義作答請自行判斷。

不反應期

心肌的不反應期很長，在收縮期間無法再被刺激，所以心臟不會像骨骼肌那樣出現強直收縮。

各種動物每分鐘心跳次數

對數尺度。年幼動物心跳較快：體型較小，且迷走神經緊張性尚未發達。大型犬 70–80、小型犬 >120。

08血管 3D：動脈、靜脈、微血管

剖開的血管壁三層 · 點選
血管壁三層
  • 內膜 Tunica intima：單層鱗狀內皮 + 基底膜 + 結締組織
  • 中膜 Tunica media：平滑肌
  • 外膜 Tunica externa：結締組織

點選模型的各層或各種血管。

動脈

  • 彈性動脈：靠近心臟；血液打入時被撐開、心室舒張時回彈
  • 肌肉性動脈：離心臟較遠；平滑肌比例較高、管腔較小 → 阻力較大
  • 小動脈：直徑 20–30 µm

微血管

  • 最小：7–10 µm，管壁只有單層鱗狀上皮
  • 氣體與養分交換處
  • 血流受小動脈收縮/舒張與微血管前括約肌調節
  • 連續型：細胞緊密；肌肉、脂肪、CNS（構成 BBB）
  • 窗孔型：管壁有孔；腎、腸、內分泌腺
  • 不連續型：細胞間有大縫隙、蛋白質可通過；骨髓、肝、脾

靜脈

  • 壓力低：約 2 mmHg（動脈平均約 100 mmHg）
  • 幫助血液回心：① 骨骼肌幫浦 ② 靜脈瓣（單向流動）③ 呼吸（吸氣時橫膈下降，腹腔壓 > 胸腔壓，血液流向心臟）

09先天免疫、後天免疫與淋巴系統

先天（非特異性）免疫

  • 以 PAMPs（病原相關分子模式）分辨自己與非自己
  • 對抗入侵病原的第一道防線：上皮屏障、胃酸、吞噬作用、干擾素、發燒
  • PAMPs 只由微生物產生：G(−) 菌的 LPS、G(+) 菌的 peptidoglycan
  • 免疫細胞表面的受體＝Toll 受體（人類已知 10 種）

吞噬細胞

  • 嗜中性球：最先抵達感染處
  • 單核吞噬細胞：巨噬細胞、單核球
  • 器官特有的吞噬細胞：肝、脾、淋巴結、肺、腦；固定吞噬細胞襯在肝、脾、淋巴結的竇狀隙
