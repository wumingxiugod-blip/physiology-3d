03細胞核、染色質與核小體

DNA 纏繞在帶正電的組蛋白上形成核小體（像串珠）。乙醯化使染色質鬆開 → 基因可被轉錄（常染色質）；去乙醯化使其緊縮 → 基因沉默（異染色質）。

組蛋白八聚體 + 纏繞的 DNA
點選組蛋白或 DNA

每個核小體 = 8 個組蛋白（H2A、H2B、H3、H4 各兩個）+ 纏繞約 1.65 圈的 DNA。

細胞核

  • 雙層核膜，兩層在核孔複合體處相連，控制分子進出
  • 核仁：製造核糖體 RNA（rRNA）

基因組 vs 蛋白質組

  • 人類約 20,000 個編碼蛋白質的基因（章末摘要寫約 25,000）
  • 卻能產生 >100,000 種蛋白質 → 選擇性剪接
  • 一個細胞只有約 300 個基因活躍（分化）

表觀遺傳

基因沉默（如 DNA 甲基化、組蛋白修飾）由配子或早期胚胎傳下，經細胞分裂帶到全身細胞 — 不改變 DNA 序列。

04DNA 複製、轉錄與轉譯（3D 動畫）

切換三個過程。複製：舊股（藍）各配一條新股（橘）→ 半保留；轉錄：RNA 聚合酶沿模板股合成 mRNA；轉譯：tRNA 依密碼子把胺基酸帶到核糖體。

複製

RNA 的種類

  • mRNA：攜帶密碼子到核糖體
  • tRNA：三葉草形，反密碼子 + 特定胺基酸
  • rRNA：核糖體的組成（4 個 rRNA + 82 個蛋白，大小兩個次單元）
  • pre-mRNA：剪去內含子、接合外顯子 → mRNA（snRNPs 組成剪接體）

RNA 干擾

  • siRNA、microRNA 與部分互補的 mRNA 結合 → 使其沉默或分解
  • 屬於基因表現的調控方式

分泌型蛋白

  • 在粗糙內質網上的核糖體合成，進入池（cisternae）
  • → 高基氏體修飾、分類、包裝 → 分泌囊泡 → 胞吐
  • 細胞內使用的蛋白多由游離的多核糖體合成

05密碼子轉換器

輸入 DNA 模板股的鹼基三聯體 → 轉錄成 mRNA 密碼子 → tRNA 反密碼子 → 胺基酸。共 64 個密碼子：61 個對應 20 種胺基酸、3 個終止密碼子；AUG = 起始（甲硫胺酸）。

06細胞週期與細胞凋亡

G₁SG₂M

示意比例（G₁ 最長、長度依細胞而異）

各期

  • G₁：DNA 指揮 RNA 與蛋白質合成，細胞生長
  • S：DNA 複製（半保留）
  • G₂：短暫間隔，準備分裂
  • M：有絲分裂 + 胞質分裂
  • G₀：不再分裂的細胞

調控與癌症

  • 週期蛋白 cyclins（與 cdk）推動細胞週期；在癌症中表現異常
  • p53：抑癌基因，DNA 受損時使週期停止或啟動凋亡
  • 致癌基因促進癌症；抑癌基因抑制癌症

細胞凋亡 Apoptosis（計畫性死亡）

  • 外在途徑：「死亡配體」（如 FAS ligand、TNF）與膜上死亡受體結合 → 活化 caspases
  • 內在途徑：粒線體釋出細胞色素 c 到細胞質 → 活化 caspases
  • 細胞縮小、DNA 斷裂、被吞噬細胞清除；不引起發炎（與壞死不同）

自噬 Autophagy

  • 自噬體包住部分胞器 → 與溶體融合消化
  • 飢餓時回收分子；也選擇性清除受損的粒線體、過氧化體

07有絲分裂 vs 減數分裂（3D 染色體）

以 2n = 4 為例：紅色＝來自母親、藍色＝來自父親，深淺代表兩對不同的同源染色體。每條複製後的染色體有兩條姊妹染色分體。

有絲分裂減數分裂
發生位置體細胞（生長、修補）性腺，產生配子
同源染色體單獨排成一列，各自分開姊妹染色分體第一次分裂並排配對（聯會、互換），每對只有一條到一極
結果2 個子細胞，各 46 條（2n）第一次後各 23 條（已複製）；第二次分開染色分體 → 4 個單倍體細胞
遺傳變異與親代相同互換 + 獨立分配 → 多樣性
