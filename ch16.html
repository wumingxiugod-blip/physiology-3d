呼吸生理

3D 氣管樹與肺泡、會呼吸的 3D 胸腔（同步壓力曲線、氣胸）、肺量計、Laplace 定律與表面活性劑、分壓與高度計算、化學受器調控、3D 血紅素與可移動的氧解離曲線（Bohr 效應、2,3-DPG）、氯離子轉移、酸鹼計算。

01呼吸系統構造：傳導區與呼吸區

約 3 億個肺泡（直徑約 100 μm）提供巨大的氣體交換面積。藍＝傳導區（氣管、支氣管、細支氣管、終末細支氣管），粉＝呼吸區（呼吸性細支氣管、肺泡管、肺泡）。

02呼吸力學（3D 胸腔 + 壓力）

波以耳定律：氣體壓力與體積成反比。吸氣時橫膈與外肋間肌收縮 → 胸腔變大 → 肺內壓低於大氣（−1 cmH₂O）→ 空氣流入；平靜呼氣是被動的彈性回縮。肋膜內壓永遠低於肺內壓。

肺的物理性質

  • 順應性：每單位跨肺壓變化的容積變化（易擴張）；肺纖維化 → 降低
  • 彈性：被拉長後回縮的傾向（彈性蛋白）
  • 表面張力：肺泡液膜產生向內的力，抵抗擴張

呼吸肌

  • 平靜吸氣：橫膈（膈神經 C3–C5）+ 外肋間肌
  • 用力吸氣：加上胸鎖乳突肌、斜角肌、胸小肌
  • 用力呼氣：內肋間肌、腹肌

氣胸

空氣進入肋膜腔 → 肋膜內壓升高到大氣壓 → 跨肺壓消失 → 該側肺因彈性回縮而塌陷。左右肋膜腔分開，所以只影響一側。

每分鐘總通氣量 = TV × 呼吸頻率 ≈ 6 L/min。解剖死腔約 150 ml，深呼吸時新鮮空氣比例較高。限制性疾病 VC 下降；阻塞性疾病（氣喘、支氣管炎）FEV₁（一秒用力呼氣量，正常 ≈ 80% VC）下降。

  • 若表面張力 T 相同，小肺泡壓力較大 → 空氣流向大肺泡 → 小肺泡塌陷
  • 第二型肺泡細胞分泌表面活性劑（磷脂 + 蛋白）降低表面張力；肺泡變小時降得更多 → 防止塌陷

  • 成人可因敗血症、肺炎造成 ARDS

05肺的氣體交換：分壓

血中的 O₂

動脈血 PO₂ 100 mmHg 時，血漿只溶 0.3 ml O₂/100 ml；紅血球內的 Hb 攜帶約 19.7 ml。PO₂ 電極只測得溶解的 O₂。

通氣–灌流配合

肺泡 PO₂ 低時，該處肺小動脈收縮（與體循環相反），把血流導向通氣好的區域。站立時肺尖通氣/灌流比較高。

高壓氣體的疾病

氧中毒、氮麻醉（潛水「深度狂喜」）、減壓病（快速上升時溶解的 N₂ 形成氣泡）。

血紅素的型式

  • 氧合血紅素／去氧血紅素（還原血紅素）
  • 碳氧血紅素：CO 與 Fe 結合（一氧化碳中毒）
  • 變性血紅素：Fe³⁺，無法攜帶氣體
  • 動脈血每克 Hb 可攜 1.34 ml O₂ → 約 20 ml O₂/100 ml

右移的因素

  • pH↓（Bohr 效應）、溫度↑、2,3-DPG↑ → 親和力↓、組織卸載↑
  • 貧血、高海拔使 2,3-DPG 增加（氧合血紅素抑制 DPG 生成）
  • 胎兒血紅素（γ 鏈）不結合 DPG → 親和力較高 → 從母體取得 O₂

遺傳缺陷與肌紅素

  • 鐮刀型貧血：β 鏈一個胺基酸置換（HbS）
  • 地中海型貧血：α 或 β 鏈合成不足
  • 肌紅素：骨骼肌與心肌中，在低 PO₂ 才釋放 O₂ 給粒線體

08二氧化碳運輸與氯離子轉移

CO₂ + H₂O ⇄ H₂CO₃ ⇄ H⁺ + HCO₃⁻
  • 紅血球內的碳酸酐酶催化 → 組織中（PCO₂ 高）向右
  • H⁺ 大部分被血紅素緩衝；HCO₃⁻ 擴散出紅血球
  • 為維持電中性，Cl⁻ 進入紅血球 → 氯離子轉移
  • 肺中 PCO₂ 低 → 反向氯離子轉移，CO₂ 被呼出
  • CO₂ 運輸形式：多數為 HCO₃⁻，部分與 Hb 結合（胺基甲醯血紅素）與溶解

10運動與高海拔

運動

  • 通氣增加（呼吸過強 hyperpnea）與代謝率相配合 → 動脈 PCO₂ 維持正常
  • 原因：本體感受器輸入、大腦輸入、PCO₂/pH 變化
  • 重度運動達無氧閾值（最大攝氧量的 50–70%）→ 肌肉釋放乳酸
  • 耐力訓練使肌肉更有效利用 O₂，延後無氧閾值

高海拔適應

  • 低 PO₂ → 過度換氣
  • 紅血球產生更多 2,3-DPG → 曲線右移、卸載↑
  • 腎分泌紅血球生成素 EPO → 骨髓增加紅血球 → 攜氧量↑
