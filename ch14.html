CO＝每分鐘左心室送入主動脈的血量＝SV × HR；SV＝EDV − ESV。拉桿或按下方「情境」看各因子如何改變 SV 與 CO。

情境

選一個情境

影響 EDV 的因子

  • 心室舒張期長短：HR↑ → 舒張期↓ → EDV↓
  • 靜脈壓力：靜脈壓↑ → 血容量↑ → EDV↑

影響 ESV 的因子

  • 動脈壓力：動脈壓↑ → 阻力↑ → ESV↑
  • 心室收縮力：回流血液↑ → 心肌纖維伸張↑ → 收縮力↑ → ESV↓

02Frank–Starling 定律

130

更多進入 → 更多輸出

心室收縮強度隨 EDV 而變：EDV 越大，心肌被拉得越長，收縮越強，SV 越大（在生理範圍內）。

  • 這是心臟內在的調節：讓左右心室輸出量保持一致
  • 交感神經（NE / E）：HR↑、收縮力↑ → ESV↓ → SV↑（整條曲線往上移）
  • 副交感神經：收縮力↓ → ESV↑ → SV↓

曲線形狀為示意。

03自主神經與血壓調控

平均血壓 正常

延腦的心臟中樞

  • 心速中樞 CAC（cardioacceleratory）→ 心率↑、收縮力↑
  • 心抑中樞 CIC（cardioinhibitory）→ 心率↓、收縮力↓

血壓控制的五個機制

  1. 血管運動中樞
  2. 壓力接受器 Baroreceptor
  3. 化學接受器 Chemoreceptor
  4. 腦部高級中樞
  5. 化學物質（激素）

1–4 屬神經機制。

壓力接受器的三個反射

  1. 頸動脈竇反射 carotid sinus reflex
  2. 主動脈反射 aortic reflex
  3. 右心房反射（Bainbridge）：靜脈壓↑ → 刺激 CAC → HR↑

補充：頸動脈竇與主動脈弓的壓力接受器感受血壓↑ → 延腦使副交感↑、交感↓ → HR↓、血管舒張 → 血壓回降（負回饋）。

循環力學

F（流量）= P（壓力）/ R（阻力）
CO = AP / PR

AP＝動脈壓，PR＝周邊阻力 → 動脈壓 = CO × 周邊阻力。

影響動脈血壓的因素

  1. 心輸出量
  2. 血液容積
  3. 周邊阻力（血液與管壁的摩擦）
    • 血管直徑
    • 血液黏稠度：RBC 數目、血漿蛋白含量、血比容

影響靜脈回流的因素

  1. 肌肉幫浦 + 靜脈瓣
  2. 胸腹幫浦：吸氣時橫膈下移，胸壓↓、腹壓↑ → 血液由腹部靜脈進入胸部靜脈；呼氣時靜脈瓣關閉防止逆流，胸部靜脈 → 右心房

流速與總截面積成反比

流速 ∝ 1 / 總截面積。截面積：微血管 > 小靜脈 > 小動脈 → 微血管的血流最慢，正好方便物質交換。

數值為教科書常見的示意值（補充）。

06胎兒循環與出生後的改變

胎兒的肺、肝、消化道還不具功能 → 用三個分流繞過它們。線條顏色代表含氧量（紅＝高、紫＝混合、藍＝低）；點選構造看說明。

胎兒循環路徑
  1. 胎盤（母體子宮絨毛交換）→ 臍靜脈（含 O₂、養分最多）
  2. → 靜脈導管（大部分繞過肝臟）→ 下腔靜脈 → 右心房
  3. 右心房 → 卵圓孔 → 左心房 → 左心室 → 主動脈 → 全身
  4. 上腔靜脈血 → 右心室 → 肺動脈 → 動脈導管（繞過肺）→ 主動脈
  5. → 腹下（髂內）動脈 → 臍動脈（O₂ 低）→ 胎盤

出生後

開始肺呼吸 → 肺血管擴張 → 動脈導管平滑肌收縮 → 卵圓孔關閉（成為卵圓窩）。臍動脈、臍靜脈及動、靜脈導管 → 形成韌帶。

07體循環的特殊區域

腦部血流

  • 內頸動脈與椎動脈兩系統形成 circle of Willis
  • 腦約佔體重 2%，但用掉約 20% 的氧
  • 缺氧 >4 分鐘 → 永久腦死
  • 主要能源：葡萄糖，其他物質嚴格管制

血腦障壁 BBB

腦部微血管內皮細胞、基底膜及神經膠細胞排列緊密，形成選擇性障壁，保護腦細胞免受傷害。

→ 第 7 章 BBB 三層結構

吻合 Anastomosis

分布到身體同一區域的 2 條以上血管相接合 → 提供替代路徑。

肝門脈循環

消化道與脾的靜脈血先經肝門靜脈送到肝臟處理，再經肝靜脈回下腔靜脈。

08失血的代償

0%

講義重點

  • 靜脈代償作用：失血約 15–20%
  • 最後防線：失血 ≥30%：中樞缺血反應 → 頸動脈竇反射 → 周邊收縮 → 周邊再擴張 → 循環崩潰 → 死亡

補充：靜脈系統是主要的血液儲存處，靜脈收縮可把儲存的血液推回循環；交感神經使心率加快、小動脈收縮以維持血壓。
