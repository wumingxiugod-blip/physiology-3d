激素的交互作用與濃度效應

  • 協同：共同作用（如 E、NE 對心臟）
  • 允許：一激素提高標的對另一激素的反應（雌二醇誘導子宮黃體素受體）
  • 拮抗：作用相反（懷孕時雌、黃體素抑制泌乳素作用）
  • 前激素 prohormone：腺體內較不活性的前驅（如胰島素原）；前驅激素 prehormone：腺體正常分泌、需在標的轉換（T₄ → T₃、睪固酮 → DHT、維生素 D₃ → 1,25-(OH)₂D₃）
  • 高濃度長期刺激 → 去敏感化 / 下調受體；因此許多激素以脈衝分泌

02激素作用機制（3D 動畫）

親脂性激素（類固醇、甲狀腺素）進入細胞與核受體結合，作為配體依賴的轉錄因子；極性激素結合細胞膜受體，經第二傳訊者作用。

03下視丘與腦下垂體（3D）

切換：後葉的激素其實在下視丘視上核、室旁核製造，經下視丘–垂體徑的軸突運到後葉釋放；前葉受下視丘的釋放/抑制激素控制，經下視丘–垂體門脈系統送達。

同時交感腎上腺系統分泌腎上腺素。長期高皮質醇抑制免疫與發炎。高等腦區（前額葉、杏仁體、海馬）協調反應。

疾病

  • 庫欣氏症候群：糖皮質素長期過高 → 脂肪重分布（水牛肩、月亮臉）、高血糖、肌肉流失
  • 愛迪生氏病（腎上腺皮質功能不全）：皮質醇不足 → 低血糖；醛固酮不足 → 失 Na⁺、留 K⁺、脫水、低血壓
  • 長期服用類固醇（如 prednisolone）後突然停藥 → ACTH 被抑制、腎上腺萎縮 → 腎上腺功能不全（見第 04 節模擬）

06甲狀腺與副甲狀腺

濾泡細胞把碘 I⁻ 主動送進膠質，接到甲狀腺球蛋白的酪胺酸上（MIT、DIT），偶聯成 T₄（DIT+DIT）與 T₃（MIT+DIT）；TSH 刺激濾泡細胞把膠質胞吞回來、釋出 T₄、T₃ 進入血液。

濾泡：一層濾泡細胞包住膠質

甲狀腺激素的作用

  • T₄（甲狀腺素）多、T₃ 少；T₄ 在標的細胞轉成活性較強的 T₃
  • 提高幾乎所有細胞的呼吸作用 → 設定基礎代謝率
  • 促進蛋白質合成；兒童生長與中樞神經發育必需

甲狀腺疾病

  • 地方性甲狀腺腫：缺碘 → T₄↓ → TSH↑ → 腺體肥大
  • 甲狀腺低下：成人黏液水腫、先天呆小症；橋本氏甲狀腺炎（自體免疫）
  • 葛瑞夫茲病：自體抗體（TSI）刺激 TSH 受體 → 甲亢、甲狀腺腫、突眼

鈣的調節

  • 副甲狀腺（嵌在甲狀腺後面）分泌 PTH → 血鈣↑（骨吸收、腎再吸收 Ca²⁺、活化維生素 D₃）
  • 濾泡旁細胞（C 細胞）分泌降鈣素 → 可能降低血鈣

07胰島：胰島素與升糖素

  • 蘭氏小島：β 細胞 → 胰島素、α 細胞 → 升糖素（δ 細胞 → 體抑素）
  • 胰島素：餐後血糖上升時分泌 → 降低血糖，促進肝醣、脂肪、蛋白質合成
  • 升糖素：禁食、血糖下降時分泌 → 肝醣分解、糖質新生、脂肪分解、酮體生成 → 升高血糖
  • 第 1 型：β 細胞被破壞 → 缺胰島素（升糖素過多）
  • 第 2 型：組織對胰島素不敏感 + 分泌不足；肥胖加重、運動改善

曲線為示意（三餐：7、12、18 時）。詳見第 19 章。

08其他內分泌腺、旁分泌與自分泌

松果體

分泌褪黑激素，夜晚最高，促進睡眠。受下視丘視交叉上核（SCN）經交感神經控制；SCN 是晝夜節律的主要中樞。

腸胃道

胃泌素、胰泌素、膽囊收縮素（CCK）、GIP 等調節消化（第 18 章）。

性腺與胎盤

睪丸間質（Leydig）細胞 → 睪固酮；濾泡顆粒細胞 → 雌二醇；黃體 → 黃體素 + 雌二醇；胎盤 → 雌、黃體素、hCG、hCS。

其他

胸腺（thymopoietin）、心房（心房利鈉激素）、腎（紅血球生成素）、肝（體介素 IGF）、脂肪（瘦體素）。

旁分泌與自分泌

  • 局部調節分子，不經血液運輸
  • 自分泌：在同一組織產生並作用；旁分泌：由一組織產生，調節同器官的另一組織
  • 例：內皮產生的 NO 使血管平滑肌放鬆
