01腎臟構造與腎元（3D）

每個腎約有 100 萬個以上腎元。濾液顏色＝滲透壓：藍 300 → 紅 1,200 → 淡 100 mOsm。切換 ADH 看集尿管產生濃縮尿或稀釋尿。

點選構造

巨觀構造

  • 外層皮質、內層髓質（腎錐體，之間為腎柱）
  • 腎錐體 → 小腎盞 → 大腎盞 → 腎盂 → 輸尿管 → 膀胱
  • 腎小體、近曲與遠曲小管在皮質；亨利氏環在髓質

血管

  • 入球小動脈 → 腎絲球 → 出球小動脈 → 腎小管周圍微血管（近髓腎元為直血管 vasa recta）
  • 兩個微血管床串聯

排尿反射

  • 膀胱壁＝逼尿肌（有縫隙接合）；內括約肌（平滑肌）、外括約肌（骨骼肌）
  • 膀胱牽張 → 薦髓 S2–S4 → 橋腦排尿中樞 → 副交感使逼尿肌收縮
  • 高等腦區抑制橋腦中樞 → 守衛反射，可延遲排尿

02腎絲球過濾與 GFR

濾液穿過三層：微血管窗孔（200–500 Å）→ 基底膜 → 足細胞的過濾裂隙（裂隙膜擋住大部分蛋白質）。淨過濾壓只有約 10 mmHg，但通透性與面積極大 → GFR 約 115–125 ml/min（每天約 180 L），尿量只有約 1.5 L（99.2% 被再吸收）。

03鹽與水的再吸收：逆流倍增系統

  • 近曲小管：約 65% 鹽與水再吸收（Na⁺ 主動、Cl⁻ 跟隨、水滲透）；不受激素調節，濾液仍等張
  • 降支：對水通透 → 水滲出，濾液變濃（約再收 20%）
  • 升支粗段：主動把 NaCl 打出、對水不通透 → 濾液變稀（約 100 mOsm），間質變濃
  • 兩支逆向流動 → 濃度差被「倍增」：皮質 300 → 內髓 1,200 mOsm
  • 直血管的逆流交換保住髓質高張；尿素由內髓集尿管滲出再循環，貢獻約一部分滲透壓
  • 集尿管對鹽不通透；有 ADH 時對水通透 → 水被高張髓質吸走 → 濃縮尿

04ADH 與水通道蛋白（3D）

上：集尿管管腔　下：血液側
  • 血漿滲透壓↑（或血量↓）→ 下視丘滲透壓受器 → 後葉釋放 ADH
  • ADH 結合集尿管細胞基底側受體 → cAMP → 含水通道蛋白的囊泡與管腔側細胞膜融合
  • 水從管腔經水通道進入細胞，再從基底側進入血液
  • 沒有 ADH → 水通道被胞吞移除 → 尿可稀到 50 mOsm、每小時可達 750 ml
  • 尿崩症：ADH 不足（中樞性）或腎對 ADH 無反應（腎性，例如鋰鹽）→ 多尿（3–10 L/天）、口渴、低張尿

  • 菊糖：過濾、不再吸收也不分泌 → 清除率 = GFR
  • 尿素：部分再吸收 → 清除率 < GFR（約 75）

腎臟疾病

  • 腎絲球腎炎：發炎使血漿蛋白漏入尿（蛋白尿）
  • 腎衰竭 → 尿素、K⁺、H⁺ 堆積，需血液透析（透析膜：小分子擴散、蛋白與血球保留）
  • 多囊腎：先天性，大量囊腫

回顧

利尿劑增加尿量 → 降低血量與血壓（治療高血壓、水腫）。環利尿劑與 thiazides 會增加 K⁺ 流失 → 可能低血鉀。
