01兩個神經元的路徑：節前與節後

自主運動需要兩個神經元：節前神經元（細胞體在 CNS）在自主神經節與節後神經元突觸，節後神經元再支配平滑肌、心肌、腺體。點選突觸看神經傳遞物與受體。

02交感 vs 副交感（3D 解剖）

切換分支與身體狀態：紅＝交感（胸腰段 T1–L2），綠＝副交感（顱神經 III、VII、IX、X 與薦段 S2–S4）。粗線＝節前、細線＝節後。點器官看雙重支配。

點選器官或神經節

或用下方按鈕選取。

交感（胸腰段）

  • 節前纖維由 T1–L2 腹根離開 → 白交通枝 → 椎旁交感鏈神經節（雙排）
  • 節前短、節後長；一個節前可分歧到多個節後 → 大量活化
  • 部分節前穿過交感鏈 → 內臟神經 → 側副神經節（腹腔、上腸繫膜、下腸繫膜）
  • 部分直接到腎上腺髓質（像變形的交感神經節）→ 分泌腎上腺素（及少量 NE）入血 → 交感腎上腺系統

副交感（顱薦段）

  • 節前起自腦幹（中腦、橋腦、延腦）與薦段 S2–S4
  • III → 睫狀神經節（眼）；VII → 翼腭、下頷下神經節（淚腺、鼻腔、下頷下/舌下腺）；IX → 耳神經節（腮腺）
  • 迷走神經 X：長節前 → 器官旁或內的終末神經節：心、肺、食道、胃、肝、小腸、大腸上半
  • 薦段 → 大腸下半、直腸、泌尿與生殖系統

03神經傳遞物與受體

膽鹼性 vs 腎上腺素性

  • 所有節前纖維：ACh（膽鹼性）→ 節後神經元上的菸鹼型受體
  • 所有副交感節後：ACh → 受動器上的蕈毒鹼型受體
  • 多數交感節後：正腎上腺素（腎上腺素性）
  • 例外：支配汗腺與骨骼肌血管的交感節後纖維是膽鹼性
  • 節後軸突有膨體 varicosities，沿途釋放神經傳遞物（en passant 突觸）
  • 非腎上腺素非膽鹼性：ATP、VIP、NO（陰莖血管舒張→勃起、腦動脈舒張）
受體機制典型作用
α₁↑ 細胞質 Ca²⁺平滑肌收縮：血管收縮、瞳孔放大肌、括約肌
α₂突觸前：減少 NE 釋放；CNS降低交感輸出（clonidine）
β₁↑ cAMP心率與收縮力增加
β₂↑ cAMP平滑肌放鬆：支氣管擴張、骨骼肌血管舒張（腎上腺素）
β₃↑ cAMP脂肪組織：脂肪分解、產熱
菸鹼型 N配體閘控陽離子通道 → 去極化自主神經節、骨骼肌（永遠興奮）
蕈毒鹼 M₃、M₅G 蛋白 → ↑ Ca²⁺平滑肌收縮、腺體分泌
蕈毒鹼 M₂G 蛋白 → 開 K⁺ 通道 → 過極化心臟：心率變慢

05雙重支配：拮抗、互補、協同

⚖️

拮抗 Antagonistic

  • 心臟：交感 β₁ ↑心率；副交感（迷走）M₂ ↓心率
  • 瞳孔：交感 α₁ 使輻射肌收縮 → 放大；副交感使環狀肌收縮 → 縮小
  • 腸胃道：交感抑制、副交感促進蠕動與分泌
🤝

互補 Complementary

  • 唾液腺：副交感 → 大量稀薄唾液；交感 → 收縮血管，唾液少而黏稠
  • 兩者都刺激分泌，只是性質不同
🔗

協同 Cooperative

  • 生殖：副交感 → 勃起（血管舒張，NO）；交感 → 射精
  • 排尿：副交感使逼尿肌收縮；交感協助括約肌張力
無雙重支配的器官：腎上腺髓質、豎毛肌、汗腺與大多數血管只有交感支配 → 靠交感神經活性增減來調節（例：交感↓ → 血管舒張）。交感神經有持續的張力性活動，不只在緊急時作用。
